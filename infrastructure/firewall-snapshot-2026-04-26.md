## Notable Configuration Details

- Default INPUT/OUTPUT/FORWARD policy: **DROP**
- Invalid packet handling: dropped via INVDROP chain (malformed TCP flags)
- ICMP ping: rate-limited to 1/sec burst 5, excess logged and dropped
- SMTP outbound: restricted to loopback, GID 12, and UID 0 only — blocks spam from compromised accounts
- Logging: blocked TCP/UDP/ICMP logged at 30/min with prefix tags for easy grep
- ALLOW/DENY ipsets: dynamic allow/deny lists managed by CSF (`chain_ALLOW`, `chain_DENY`, `chain_6_ALLOW`, `chain_6_DENY`)
- IPv6 mirrors IPv4 rules with same port set
